# Bases de datos

Esta carpeta contiene las bases de datos utilizadas en el proyecto de contagio financiero y comovimiento bursátil latinoamericano.

## Contenido

- **originales/**: bases de datos originales de índices bursátiles y tipos de cambio.
- **base_unidas.xlsx**: base de datos consolidada utilizada para el análisis econométrico y la estimación de los modelos en R.

Se conservan los archivos originales para facilitar la trazabilidad, verificación y reproducibilidad de los resultados.
